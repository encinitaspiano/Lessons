# Action Items box (required on every Lesson Challenge)

Every content JSON needs an `"action_items"` list of 4-9 short strings.
The builder shows them FIRST on the page, above Terms to Know, and adds the
heading, the line "Key points we covered." and the starred-items note about
the practice log by itself. Do not write those three things.
The old "This week's practice" list at the bottom of the summary is gone;
Action Items replaced it, so do not add a practice section to the summary.

What the box is: a little summary of the key points covered in the lesson and
what to work on before the next one. Like Otter's action items, but corrected
from the FULL transcript. Never copy Otter's list: it merges different books
into one item, misses pieces and gets details wrong.

Rules
- One item per piece / book / exercise, in lesson order.
- Start each item with a short label and ": " (shown in bold), for example
  "Jingle Bells: Start at measure 13 and play to the end 3 times at 90. Then
  play the whole song at 90 and move up to 95, 100, then 105 by next lesson."
- One or two lines each (260 characters max), written to the student in the
  teacher's voice, with his characters (Sergeant Metronome, the speed monkey).
- Say what to practice (which measures), the tempo or tempo ladder, how many
  times, and the page / lesson number of any book assignment.
- Where fingering was written in for a spot: get the fingering solid first,
  then add the metronome.
- Include things assigned away from the piano (drum along to music, ask a
  parent a musical question). For kids, add one item addressed to the parent
  when the parent was asked for something ("For Dad: ...").
- Keep fine detail OUT (how many times a note repeats, step vs skip, a single
  finger number). Turn those into Level 2 quiz questions instead.
- Music only. No check-off boxes. ASCII only.
- Name a piece or book only when the transcript makes it clear. Otherwise
  describe it ("the song with the red bracket") and say so in the report.
- Check every item (piece, measures, tempo, page number) against the
  transcript and the summary before building.
